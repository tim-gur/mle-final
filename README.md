# mle-final
# Цели и использованные технологии
Данный проект решает задачу создания рекомендательной системы товаров для магазина. Целевым действием в рамках проекта является добавление в корзину.  
В качестве структуры рекомендательной системы было решено выбрать двухстадийный подход с дополнительными признаками.  
В данном случае использовалась коллаборативная матрица als, контентная матрица схожести по категориям, дополнительные признаки и ансамблирование финальных рекомендаций с помощью catboostclassifier.  

Исследование:  
- Контентная матрица по схожести категорий на данный момент не выдает слишком точные результаты (потому что в датасете у большинства пользователей очень мало интеракций) и требует слишком много ресурсов для построения. Пока от нее было решено отказаться.  
- 1 версия: метрики модели низкие, но надо сравнить с топ 100, также разные k. Также feature importance показывает адекватные данные.

Архитектура рекомендательной системы:  
- Коллаборативная матрица ALS
- Контентая матрица по схожести жанров. В связи с тем, что у большинства пользователей ~900k всего одна интеракция, данный признак не выдает точные рекомендации. Для более точного обучения catboost параллельно как дополнительный признак подается общее количество интеракций пользователя. Также пользователям с кол-вом интеракций <=2 выдается 5 кандидатов, остальным 100.
- Дополнительные признаки:
1. общее кол-во интеракций у юзера
2. общее кол-во интеракций у айтема
3. общее кол-во просмотров у юзера
4. общее кол-во покупок у юзера
5. общее кол-во просмотров у айтема
6. общее кол-во покупок у айтема
7. категория айтема

# Шаги для воспроизведения проекта
1. Воссоздание среды
```bash
    cd mle-final
    pip install -r requirements.txt
```
2. Запуск mlflow
```bash
    sh run_mlflow_server.sh
```
3. Обработка данных
- объединение item_properties в один df
- замена timestamp на формат даты
- создание отдельного df с айтемами и их категориями
- создание топ 100
- разделение данных по времени

```bash
    python3 files_processing.py
```
